# 私有资料与发布边界

本仓库不以“删掉姓名”作为脱敏完成。手机号、受访者编号、Garmin内部用户ID、设备序列号、活动ID、FIT文件名、绝对时间、GPS轨迹、健康数据、登录缓存和账号截图，都可能直接或间接关联个人。

## 公开版本包含什么

- 中文教程、来源网址、聚合规则和已知限制。
- 通用提取/清洗/导出代码，凭据由环境变量提供。
- 字段清单和中文数据字典。
- 只有一行表头的演示CSV。
- 明确占位的配置以及代码中的虚构测试输入。

## 本地保留什么

账号与受访者映射、原始FIT/JSON、解析CSV、真实Excel、时间序列、分组表、问卷、轨迹、个人截图、登录令牌和运行日志都留在私有目录。不要复制进发布目录；也不要依赖已有Git历史中的删除来“去除”泄露。

## 发布步骤

1. 从干净的代码目录新建独立Git仓库，不在包含研究资料的父目录初始化Git。
2. 使用明确的发布文件白名单。真实数据文件、二进制文件及符号链接不进入仓库。
3. 执行 `python src/privacy_check.py`，人工核查文档、配置、代码注释及示例。
4. 暂存后执行 `python src/privacy_check.py --staged`，确认每个示例CSV只有表头。
5. 核查提交作者邮箱及暂存文件，避免把私人邮箱、环境变量或系统路径写入提交。
6. 上传后读取远端文件列表，确认没有私有资料、旧提交或额外附件。

检查器会阻止常见手机号、个人邮箱、研究编号、用户主目录路径、GitHub令牌和私有文档链接，但静态检查不能保证识别所有形式的秘密。发布版本仍需内容核查。原始照片或截图不在发布白名单中，避免仅遮盖可见姓名却遗漏坐标或元数据。

本项目公开的是工具与方法；原始受访者数据不会随教程一起发布。
