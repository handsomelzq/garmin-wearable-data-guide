# 验证范围

公开通用代码通过16项离线测试，包括：固定心率槽位分母、80%边界、重复记录、哨兵值、午夜累计归属、压缩时间戳回绕、零与空白、日期时区转换、文本不作为Excel公式、发布白名单及暂存区内容检查。

小型虚构数据完成process.py → export_excel.py流程，验证一日1440分钟、三个数据工作表与中文README、真实Excel日期、冻结窗格、筛选表和缺失说明。测试输入仅用于验证规则，不是研究样本。

公开版的下载配置已做静态检查与离线参数测试，但未使用新的配置重新登录真实账号。联网下载需要在授权账号与可用网络下核验；第三方接口和新设备字段可能变化。不要把离线测试通过解释成所有账号与设备都已测试。

运行：`python -m unittest discover -s tests -v`。首次安装依赖按教程用uv；已有项目环境可直接执行，无需重复安装。
